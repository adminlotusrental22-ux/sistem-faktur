# Aset template invoice

image1.png (logo) dan image2.png (tanda tangan) diambil dari salinan baca-saja Template Faktur Google Docs yang sudah dipakai GAS. Dokumen sumber tidak diubah.

ID template: 1F2rHCoFElZTpKjolx1uYHLKYRk2jacbljG20j8et2Nc

Font Plus Jakarta Sans berasal dari repositori resmi google/fonts, direktori ofl/plusjakartasans, dengan lisensi OFL.txt. File Regular dan Bold merupakan instans statis bobot 400 dan 700 dari font variabel tersebut.

Aset lokal digunakan untuk preview demo. PDF operasional tetap dihasilkan oleh template Google Docs asli. Jika logo, tanda tangan, rekening, atau isi template berubah, perbarui preview lokal juga.
